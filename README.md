# 公共服务通知改写与关键条件完整性检查

本项目整理公共服务部门需要把政策通知改写成面向不同读者的易读版本。日期、资格条件和例外事项常被分散在多个段落；若只按句子相似度判断改写质量，简化文本可能漏掉会改变办理资格的否定条件，或保留过期流程。

演练资料位于 `data/notice.json`，内容为合成记录，保留不同来源的原始表述和修订关系。项目环境使用 Python 3.11 标准库。

当前资料检查入口为 `python3 -m unittest discover -s tests -v`。检查仅确认 JSON 文件可以读取、记录字段完整且每条原文存在，不会生成业务判断。尚无面向使用者的业务命令。
